# Approved visual reference

[approved-pixel-style.png](approved-pixel-style.png) is the exact generated comparison sheet approved by the user on September 29, 2026.

Provenance: generated in this project's conversation at the user's request and selected by the user as the preferred direction. It contains four adventurer sprites, four ground textures, and eight small objects/creatures.

Use it for colour, silhouette, expressiveness, and visual cohesion. It is a style reference, not a production atlas, a final character roster, or an exact 16x16 grid. Production assets still need consistent native pixel dimensions, transparency, tile seams, scale, and animation.

The earlier direct-drawn map's layout was rejected. It is not included as a level template.

See [the decision log](../../docs/DECISIONS.md) for the confirmed and open art choices.
